# Integrated UCSD collection and summary results

Both reviewed publication branches are included. Their original receipts are preserved byte-for-byte under `collection/` and `summaries/`; the three same-name receipt conflicts were combined here without dropping either source. User source worktrees and their uncommitted changes remain untouched.

Collection: source code, public official-source evidence/reviews, and the lossless `data/ucsd/accepted-export-20261017.json.gz` accepted subset (6,233 professors and 902 lab-array entities). The served `data/research-atlas.json` remains the existing baseline as in the reviewed publication branches; merging these branches does not promote the frozen export into served data.

Summary: 916 processed baseline-plus-reviewed-addition records; 752 supported lab/group summaries and 600 verified original lab/group URLs, with 60 partial and 90 unresolved records. Summary and collection counts use different grains. Original stable IDs, evidence URLs/quotes/dates/hashes and explicit uncertainty remain.

The eligible request queue completed; the full scientific identity/source review did not. Existing faculty holds, access restrictions, lab source constraints and description-scope holds are retained. Do not treat broken links as closure or combine people by similar names. No new research requests are part of this integration.

Internal user authorizations, private conversation/Library metadata and raw response caches remain excluded. The original local evidence archive remains available separately. Only normal main workflows may run after the authorized main push; no extra deployment or configuration change is requested.
